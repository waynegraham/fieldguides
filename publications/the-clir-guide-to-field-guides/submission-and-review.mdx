## Convenient. Open. Supported.

Authors submit their manuscripts for the Guides to CLIR as Google Docs. Each section of the guide should be organized under a Document tab, using subtabs as needed for longer sections. Authors can choose to make a copy of this document as a model. CLIR will prepare the manuscript as a release on GitHub pages.

## Internal Review and Release

The process of review and release of the Guides is as follows:

| Milestone                    | Description                                                                                                                                                                                 | Expected outcome                                                                                    |
| :--------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------------------- |
| Kickoff                      | Authors meet CLIR staff editor                                                                                                                                                              | Finalize and issue contract                                                                         |
| Contract                     | Get contract signed                                                                                                                                                                         | Signed contract                                                                                     |
| Manuscript Draft             | Complete draft manuscript                                                                                                                                                                   | Completed Manuscript, Google Doc sectioned using Document Tabs                                      |
| Internal Review              | CLIR editor provides comments                                                                                                                                                               | Draft with comments                                                                                 |
| Revised Manuscript Submitted | Authors revise draft                                                                                                                                                                        | Revised draft                                                                                       |
| Copyediting                  | Copy Editor submits stylistic comments                                                                                                                                                      | Draft with corrections, CLIR style-compliant                                                        |
| Draft Into GitHub Pages      | CLIR staff converts manuscript                                                                                                                                                              | Preliminary GitHub Pages layout                                                                     |
| Layout finalized             | Authors submit comments and request changes to layout                                                                                                                                       | Finalized, corrected GitHub Pages version of Guide                                                  |
| Public release               | CLIR makes public announcement and authors promote Guide, tracking feedback and suggestions and submitting periodic revisions to CLIR for a period of one (1) year from public release date | Revised version of Guide archived in CLIR repository, public announcements of significant revisions |
